\section{Выводы}

В ходе выполнения работы была реализована поисковая система, обеспечивающая эффективный сбор данных, лингвистическую обработку, индексацию и поиск по корпусу спортивных новостей. Система демонстрирует хорошую производительность при поиске по корпусу из 30 000 документов. Работа позволила глубже понять принципы работы с информационными системами и большим объемом данных.
