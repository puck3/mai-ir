\section{Задание}

Необходимо разработать поисковую систему, включающую следующие компоненты:
\begin{enumerate}
    \item \textbf{Сбор данных (Crawler):} Робот для автоматического скачивания текстовых документов из Интернета.
    \item \textbf{Лингвистическая обработка:} Токенизация текста и стемминг для русского и английского языков.
    \item \textbf{Анализ:} Проверка выполнения закона Ципфа для собранного корпуса.
    \item \textbf{Индексация:} Программа на языке C++ для построения инвертированного индекса.
    \item \textbf{Поиск:} Реализация булева поиска (операторы AND, OR) по построенному индексу.
\end{enumerate}
